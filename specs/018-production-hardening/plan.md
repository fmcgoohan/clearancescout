## Summary

Execute a bounded correctness and production hardening pass across the entire ClearanceScout system. Ensure `CLOUD_MODE` fails closed to `INSUFFICIENT_EVIDENCE` upon any search failure or unmitigated fallback fixture; treat `PARALLEL_LIVE` zero-hit searches as authentic completed live research without inventing fake facts; integrate Gemini structured occurrence context interpretation with deterministic TypeScript state ownership; introduce granular placeholder scoping; enforce strict `WORKING_CLEAR` shooting readiness standards; provide genuine PDF text stream extraction with visible `400` failure handling; enforce `CLOUD_MODE` sample script demo boundaries; and reconcile all documentation and `package.json` to reference `parallel-web` with zero claims of unused MCP servers.

## Technical Context

**Language/Version**: TypeScript 5.5 (Node.js $\ge 20.x$, ES Modules)  
**Primary Dependencies**: Express 4.21, React 18.3, Vite 5.3, `@google/genai` (Gemini 3.6 Flash), `parallel-web` 1.3.0, `@google-cloud/firestore` 7.11  
**Storage**: In-memory repository pattern with Cloud Firestore synchronization (`ProjectRepo`, `EntityRepo`, `AssessmentRepo`, `RightsRepo`, `PlaceholderRepo`, `OverrideRepo`)  
**Testing**: Vitest 1.6, Supertest 7.0  
**Target Platform**: Google Cloud Run (Linux x86_64 container, Node 20 runtime)  
**Project Type**: Full-stack web application (`server/` Express backend + `src/` Vite/React frontend)  
**Performance Goals**: Script parsing $<2$s, occurrence context evaluation $<1.5$s per scene, clearance binder export $<500$ms  
**Constraints**: Zero raw chain-of-thought surfaced/logged; strictly fail-closed in `CLOUD_MODE`; zero fictitious facts invented  
**Scale/Scope**: Screenplays up to 120 scenes, 500+ entity occurrences, 100+ clearance records
