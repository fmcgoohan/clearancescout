# Implementation Plan: ClearanceScout MVP Engine

**Branch**: `002-clearancescout-mvp` | **Date**: 2026-08-17 | **Spec**: [`specs/002-clearancescout-mvp/spec.md`](spec.md)

**Input**: Feature specification from `/specs/002-clearancescout-mvp/spec.md`

## Summary

ClearanceScout MVP Engine formalizes multi-format screenplay ingestion (Plaintext, Fountain, and PDF), 5-category entity detection (Brands & Trademarks, Copyrighted Art & Music, Living Public Figures, Proprietary Locations, and Graphic Text / Props) with semantic canonical deduplication in Firestore, live trademark and web research grounding via `@parallel-web/sdk` native ADK tools, a 3-step hybrid contextual risk evaluation engine assigning formal constitutional statuses (`NO ISSUE SURFACED`, `REVIEW RECOMMENDED`, `ACTION REQUIRED`, `INSUFFICIENT EVIDENCE`), era-appropriate visual asset replacement cards generated by Google Imagen 3 / Gemini Image Generation, real-time observable SSE timeline streaming with strict chain-of-thought privacy sanitization, and an auditable timestamped Project Clearance Binder export.

---

## Technical Context

- **Language/Version**: TypeScript 5.x / Node.js 20+
- **Primary Dependencies**: `@google/adk`, `@google/genai`, `@parallel-web/sdk`, `@google-cloud/firestore`, `express`, `react`, `vite`
- **Storage**: Google Cloud Firestore (Native Mode)
- **Testing**: `vitest` (unit, contract, and integration tests)
- **Target Platform**: Google Cloud Run (stateless containerized API) + Web Browsers (Vite/React SPA)
- **Project Type**: Web application (`server/` Express API + `src/` React frontend)
- **Performance Goals**: Parse 100-page screenplay <30s; generate visual placeholder card <15s; compile clearance binder <5s
- **Constraints**: Strict code isolation (`server/` backend, `src/` frontend); zero raw model chain-of-thought exposure; 100% citation provenance retention
- **Scale/Scope**: Multi-scene screenplays with 500+ entity occurrences across 5 categories
